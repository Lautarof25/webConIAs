# Clases Rápidas — Creá tu página web profesional
Descripción del curso

Clases prácticas y guiadas para que, en sólo 2 encuentros, aprendas a crear, publicar y mantener tu propia página web profesional. El curso está pensado para emprendedores, comercios y personas que quieren tener presencia en internet sin depender de terceros.

Qué vas a lograr

- Diseñar una página web moderna y responsive.
- Publicarla en un hosting funcional.
- Medir resultados básicos con analítica.
- Mantener y actualizar el contenido por tu cuenta.

Formato del curso

- Duración: 2 clases de 2 horas cada una.
- Modalidad: Online o presencial.

Programa (resumido)

1) Clase 1 — Uso de herramientas de IA y desarrollo web básico
	- Conceptos básicos: HTML y CSS
	- Estructura de la página: secciones, hero, cards
	- Responsive básico y layout
    - Uso de herramientas de Inteligencia artificial para crear webs.

2) Clase 2 — Publicación y mantenimiento
	- Ajustes de estilo y adaptabilidad
	- Publicar en hosting (opciones gratuitas)
	- Integrar analítica y buenas prácticas

Requisitos

- Tener una computadora con conexión a internet.
- No se requieren conocimientos previos.

Materiales entregables

- Plantilla base con diseño profesional.
- Guía paso a paso para publicar la web.
